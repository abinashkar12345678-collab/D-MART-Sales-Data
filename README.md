Project Overview
The D-Mart Sales Data Dashboard is an interactive Power BI project designed to analyze retail sales performance across different categories, sub-categories, regions, and customer segments. The dashboard provides clear business insights through KPIs, sales trends, profit analysis, payment mode analysis, and future sales forecasting.

Contents
Sales KPI Analysis
Category & Sub-Category Performance
Year-over-Year (YoY) Sales Trends
Profit Analysis
Regional Sales Filtering
Payment Mode Analysis (COD vs Online)
6-Month Sales Forecast
Segment-wise Sales Distribution

Analyze profit trends over time
